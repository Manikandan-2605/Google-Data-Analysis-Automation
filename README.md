Google Data Analysis Automation

Project Overview

A Python-based data analysis automation project that reads sales data from a CSV file, cleans the dataset, calculates sales revenue, generates charts, and creates an automated sales report.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

Features

- CSV dataset loading
- Missing value detection and removal
- Duplicate record removal
- Sales revenue calculation
- Best-selling product identification
- City-wise sales analysis
- Automatic chart generation
- Automated text report generation
- Cleaned dataset export

Installation

1. Clone or download this repository.
2. Install the required libraries:

pip install -r requirements.txt

3. Run the project:

python main.py

Output

The project automatically generates:

- Cleaned sales dataset
- Product-wise sales chart
- City-wise revenue chart
- Sales analysis report
